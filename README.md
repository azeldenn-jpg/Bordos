# Bord'os

Appli perso d'étirements (souplesse, mobilité) avec un petit dragon animé. Vanilla HTML/CSS/JS, installable sur l'écran d'accueil (PWA), fonctionne hors connexion.

- `docs/savoir.md` : base de connaissances scientifique (sources) qui guide toutes les règles de l'appli
- `js/data.js` : bibliothèque d'exercices (consignes, sensations, variantes, précautions, contracter-relâcher)
- `js/figure.js` : moteur du personnage (vue de profil et de face)
- `js/app.js` : générateur de séances, programmes, constructeur, lecteur de séance
- `js/progress.js` : régularité, bilan de mobilité, volume hebdo, photos, historique
- `js/profile.js` : niveau, Mon corps, sons, synchronisation, questionnaire
